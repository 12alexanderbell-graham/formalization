# Answers (from CLAIMS.md and STATE.md only)

Common basis: each theorem's CLAIMS.md entry carries a generated line "the statement is proved in module `Checked...` of `Checked`; axioms ... `Classical.choice`, `Quot.sound`, `propext`" and "open fidelity objections on record ...: none". All five are proved and listed, so (a) = yes for each.

## 1. lookback_second_order
(a) yes. (b) all: the scale factor a is arbitrary, and the model has no free physical parameter. Hypotheses: a differentiable near t0, deriv a differentiable at t0, a t0 != 0, deriv a t0 != 0. The conclusion is a little-o expansion t0 - t - (z - (1+q0/2) z^2)/H = o(z^2), with z the redshift. It is a local, as t -> t0, statement.
(c) "**For every** `a : ℝ → ℝ`, `t₀ : ℝ`: **assuming** 1. `∀ᶠ (t : ℝ) in nhds t₀, DifferentiableAt ℝ a t` ..." (CLAIMS.md l.39-44). STATE.md l.560: "PROVED `Checked.Cosmography.lookback_second_order`".

## 2. avilesL0Claim_false
(a) yes, but it is a negative result. It proves that a published formula is wrong, not a positive law. (b) particular: it is the negation of a "for all Omega, a, t0" claim, so it only says some flat-LCDM case breaks it. This page does not give the Omega. The witness is in `AvilesWitness.printedL0_false_at`, which I did not open. The claim that fails is cosmoCoeff 5 (lerk) = 1 + 3 Omega - 27/2 Omega^2 for flat LCDM. Matter density Omega is a free parameter there. Do not read it as "false for every Omega".
(c) "it is false that (`AvilesL0Claim`)" and "means for every `Ω : ℝ`, for every `a`, for every `t₀` ... then `cosmoCoeff 5 a t₀ = 1 + 3 * Ω - 27 / 2 * Ω ^ 2`" (CLAIMS.md l.109-120). STATE.md l.561: "PROVED (F1) ... `avilesL0Claim_false`".

## 3. gelfand_extrema
(a) yes. (b) no parameters: the equation w'' + (2/s) w' + e^w = 0 with w(0) = 0 is fixed. The dimension is fixed at 3 and lam is not a parameter. It is a statement about the one regular solution, with hypotheses on w and phi only. The numeric windows 4.071496844 <= zeta_0 <= 4.071496845 and lam(zeta_0) in [3.321992118, 3.321992119] are part of the conclusion. STATE.md notes the equation sign (the exponent's sign) is the inverse of the "model".
(c) "**For every** `w : ℝ → ℝ`, `φ : ℝ → ℝ`: **assuming** 1. for every `s : ℝ`, if `s ∈ Set.Ici 0`, then `HasDerivWithinAt w (φ s) (Set.Ici 0) s`" (CLAIMS.md l.6677 ff.). STATE.md l.221: "`gelfand_extrema` ... PROVED (CI 43721065108 ... green on every job".

## 4. gelfand_pde_radial_many_centre
(a) yes. The first freeze fell to the referee and was replaced by the corrected one; the page lists the corrected one. (b) particular, for Delta u + lam e^u = 0 in the unit 3-D ball with u = 0 on the sphere (radial, classical): (i) lam = 2 exactly: infinitely many solutions with pairwise distinct centre values. (ii) for every N there is eps > 0 such that every lam with |lam - 2| < eps has N such solutions, with eps not given explicitly. (iii) every lam with 2 <= lam < 3.321992118 has at least two. It does not claim anything for lam < 2 or lam <= 0, and it gives no exact counts here (those are `gelfand_pde_radial_count`). Beyond 3.3219921 (lam*) there are no solutions (separate theorem).
(c) "3. for every `lam : ℝ`, if `2 ≤ lam`, then if `lam < 3.321992118`, then there is `u` ... such that there is `v` ... `u 0 ≠ v 0`" (CLAIMS.md l.6700 ff.). STATE.md l.214: "PROVED (CI 44275141268 ... green on every job".

## 5. fs_neg_reversed_wall_shear_3_exists
(a) yes. (b) particular: only beta = -3/100 = -0.03 (the equation is q' = -f q - (-3/100)(1 - p^2)). It states existence of a reversed-flow Falkner-Skan solution with f(0) = p(0) = 0, p -> 1, -1 <= p <= 1, and wall shear -0.0825629652 < q(0) < -0.0825629651. The sibling theorems `_2_` and `_1_` cover beta = -0.02 and -0.01. It is an existence claim for that one row of the Ganapol 2010 Table 7, not for other beta.
(c) "`HasDerivWithinAt q (-(f η * q η) - -3 / 100 * (1 - p η ^ 2)) (Set.Ici 0) η`" ... "`-825629652e-10 < q 0`) and (`q 0 < -825629651e-10`)" (CLAIMS.md l.6473 ff.). STATE.md l.147 describes it as PROVED.
