# Notes
- Mass in ball: integral of 4*pi*r^2 e^w = 4*pi*s^2*(-phi), since (s^2 phi)' = -s^2 e^w. Pressure-confined mass scales as (mass)*(pressure)^(-1/2) in physical units with length scale ~ rho_c^(-1/2), giving m ∝ s^2 (-phi) e^(w/2). So P=2, D=2.
- Singular sphere w = log(2/s^2): phi = -2/s, e^(w/2) = sqrt2/s, so s^2(-phi)e^(w/2) = 2*sqrt2, constant. Dividing by sqrt(4*pi) (F=4): limit 2*sqrt2/sqrt(4 pi) = sqrt(2/pi), so G=2.
- Consecutive extrema alternate max/min, so next extremum is index step A=1. Sixth extremum (first max is first) has ξ-index 5, so M=5.
