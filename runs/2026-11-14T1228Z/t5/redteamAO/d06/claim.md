Reader would wrongly believe: that finding F14 (Fazio's printed reverse-flow Falkner-Skan wall shear -0.005158) has a second Lean record, `F14_reversed_wall_shear_unique`, that states a universal fact about every solution. The generated heading reads "### F14 — generated heading (do not edit): records `F14_reversed_wall_shear`, `F14_reversed_wall_shear_unique`; printed values …" and the generated Correct line ends "…; `F14_reversed_wall_shear_unique` (for every data meeting its hypotheses): the certified values below." A scientist who relies on the generated part only reads this as: Lean certifies the reverse-flow wall-shear statement for every solution (i.e. the printed value is excluded for all of them, uniqueness of the reverse-flow branch).
Why it is false: no such record exists. Checked/Records/FalknerSkan.lean has exactly one record for F14, `F14_reversed_wall_shear : ∃ f p q, … ∧ RoundsTo (q 0 - printedFazioRevWall) 0.0000006 7` — an existence statement ("there are data meeting its conditions"); the F14 notes themselves say uniqueness of the reverse-flow branch is not proved. The extra record lives only in one indented note line of F14 (an "Unchecked note", extended with a Fidelity-audit sentence) in which the lines of a block opener, a record header and a quantifier line are separated by U+2028 (LINE SEPARATOR). `check_findings.record_items` (the reader of the generated heading, Printed and Correct lines) splits FINDINGS.md with `str.splitlines()`, which also splits at U+2028, and so sees a second generated block; FB10, FB14, FB1/FB8 and check_numbers G2/G3 split at "\n" (and use `^…$` regexes), see one note line, and accept it (it starts with two spaces, carries no mark of generated text, is not a heading/HTML/quote). FB10 and FB9 then only compare the generated lines with `generated_*` run on the same text, which the author regenerates exactly as the real generator would on that file. (The two stray backticks around the planted pieces keep StatementDeps.lean's citation rule, which pairs backticks, off the invented record name.) A true statement in the same shape would not be possible for a real record name of an existence record (FB5 rejects "every" on it); an invented name is outside `cb` and escapes FB5.
