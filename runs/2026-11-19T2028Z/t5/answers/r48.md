## 4. gelfand_pde_radial_many_centre
(a) yes. It is listed with a generated Status. STATE.md contains no withdrawal of it. The only "REFUTED" item (l.506) is an earlier first freeze, "not a headline".
(b) "particular". The PDE is Δu + lam e^u = 0 in the unit 3-ball with u=0 on the sphere, radial solutions. Three ranges:
 (i) lam = 2: infinitely many solutions with distinct centre values.
 (ii) for every N there is eps>0 such that every lam with |lam-2| < eps has N solutions with distinct centre values.
 (iii) every lam with 2 <= lam < 3.321992118 has two solutions with distinct centre values.
 There is no claim for lam outside these ranges.
