- Singular solution w = log(λ∞/s²): w'' + 2w'/s = -2/s², e^w = λ∞/s², so λ∞ = 2 (B = 2).
- Linearise w = w_s + v: v'' + (2/s)v' + (2/s²)v = 0. With v = s^a: a² + a + 2 = 0, so a = -1/2 ± i√7/2 (N = 7).
- λ = 2e^v, so λ-2 ≈ 2v ~ s^{-1/2} cos((√7/2) ln s + φ). Consecutive turning points (alternating max/min, A = 1) are asymptotically half a period apart in ln s: Δ = 2π/√7. The amplitude ratio is e^{-Δ/2} = e^{-π/√7}, with sign -1. This matches the claim with N = 7.
