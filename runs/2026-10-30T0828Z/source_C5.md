# Source C5 (verbatim from the typeset PDF, arXiv:1205.3421v3, Sec. X, pp. 105–111)

K. Bamba, S. Capozziello, S. Nojiri, S. D. Odintsov, "Dark energy cosmology: the equivalent description via different theoretical models and cosmography tests", Astrophys. Space Sci. 342, 155 (2012), arXiv:1205.3421v3.

Cosmographic parameters (Eqs. 10.1–10.5): H(t) ≡ +(1/a) da/dt, q(t) ≡ −(1/a)(d²a/dt²)(1/H²), j(t) ≡ +(1/a)(d³a/dt³)(1/H³), s(t) ≡ +(1/a)(d⁴a/dt⁴)(1/H⁴), l(t) ≡ +(1/a)(d⁵a/dt⁵)(1/H⁵); subscript 0 = value at the present time t₀. Redshift: 1 + z = a(t₀)/a(t).

p. 108: "In standard applications, other quantities can result in become useful
• the luminosity distance: d_L = [a(t₀)/a(t₀ − D/c)] (a(t₀) r₀)   (10.26)
• the angular-diameter distance: d_A = [a(t₀ − D/c)/a(t₀)] (a(t₀) r₀)   (10.27)
where r₀(D) is given by r₀(D) = sin(∫_{t₀−D/c}^{t₀} c dt/a(t)) for K = +1; ∫_{t₀−D/c}^{t₀} c dt/a(t) for K = 0; sinh(∫_{t₀−D/c}^{t₀} c dt/a(t)) for K = −1.   (10.28)"
(D = c(t₀ − t*) is the light-travel distance, t* the emission time.)

p. 110: "Using these definitions for luminosity distance, we acquire d_L(z) = (cz/H₀)[D⁰_L + D¹_L z + D²_L z² + D³_L z³ + D⁴_L z⁴ + O(z⁵)]   (10.38)
[...] We define Ω₀ = 1 + Kc²/(H₀²a₀²), which can be considered a purely cosmographic parameter, or Ω₀ = 1 − Ω_K⁽⁰⁾ = Ω_m⁽⁰⁾ + Ω_r⁽⁰⁾ + Ω_X⁽⁰⁾ [...] With these parameters, we obtain
D⁰_{L,y} = 1,   (10.52)
D¹_{L,y} = −(1/2)(−3 + q₀),   (10.53)
D²_{L,y} = −(1/6)(12 − 5q₀ + 3q₀² − j₀ − Ω₀),   (10.54)
[...] Previous relations have been derived for any value of the curvature parameter."

The y-series itself is not printed. The subscript y refers to the y-redshift y = z/(1+z) of Cattoën & Visser (2007, arXiv:0710.1887, Eq. (52): d_L(y) = d_H y{1 − ½[−3 + q₀]y + ⅙[12 − 5q₀ + 3q₀² − (j₀ + Ω₀)]y² + O(y³)}, d_H = c/H₀), which the review reproduces.

Claim to formalize (C5): for a spatially flat (K = 0) FLRW model, d_L(y) = (cy/H₀)[D⁰_{L,y} + D¹_{L,y} y + D²_{L,y} y² + O(y³)] with the coefficients as printed in (10.52)–(10.54).
