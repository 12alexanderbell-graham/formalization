C. Cattoën and M. Visser, "The Hubble series: convergence properties and redshift variables", Class. Quantum Grav. 24, 5985 (2007), arXiv:0710.1887v1.

Sec. 2 (Eq. 5; referee correction, first written as Eq. 3): "• The 'deceleration distance': d_Q = d_L/(1 + z)^{3/2}." (also d_F = d_L/(1+z)^{1/2}, d_P = d_L/(1+z), d_A = d_L/(1+z)².) Here d_L is the luminosity distance of an FLRW model; d_H = c/H₀ is the Hubble distance.
Eq. (16): "Furthermore we choose to set Ω₀ = 1 + k d_H²/a₀² = 1 + kc²/(H₀²a₀²)."
The y-redshift: y = z/(1 + z). H₀, q₀, j₀ are the present Hubble, deceleration and jerk parameters: H = ȧ/a, q = −(ä/a)H⁻², j = (a⃛/a)H⁻³.

Eq. (59): "d_Q(y) = d_H y{1 − (q₀/2) y + (1/12)[3 − 2q₀ + 12q₀² − 4(j₀ + Ω₀)] y² + O(y³)}."

Claim to formalize (C1): for a spatially flat (k = 0, so Ω₀ = 1) FLRW model, with luminosity distance d_L = a₀(1+z)∫_t^{t₀} c dt'/a(t') (t the emission time), Eq. (59) holds.
