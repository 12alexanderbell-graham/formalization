# Notes (second blind reader)

- Mass inside s: 4π s²(−φ) (since (s²φ)' = −s² e^w). Dividing by sqrt of pressure e^{w}, i.e. multiplying by e^{w/2}: s²(−φ)e^{w/2}. Singular solution w = log(2/s²): −φ = 2/s, e^{w/2} = √2/s, product = 2√2, constant. So P = 2, D = 2.
- Normalising by √(4π): m = s²(−φ)e^{w/2}/√(4π), so F = 4. Singular value = 2√2/√(4π) = √(2/π), so G = 2.
- Linearisation: w = log(2/s²) + v(t), t = ln s gives v'' + v' + 2v = 0, roots (−1 ± i√7)/2. Period in t is 4π/√7. Extrema alternate every half period 2π/√7, so the radius quotient tends to exp(2π/√7): X = 2, Y = 7. Deviation decays like e^{−t/2}, so the deviation quotient tends to −exp(−π/√7), consistent with the template.
- Indexing: ξ 0 is the first extremum, so the seventh is ξ 6 and the sixth is ξ 5: A = 6, B = 5.
