# Source C3 (verbatim from the typeset PDF, arXiv:0802.1583v2, Appendix A, p. 15–16)

S. Capozziello, V. F. Cardone, V. Salzano, "Cosmography of f(R) gravity", Phys. Rev. D 78, 063504 (2008), arXiv:0802.1583v2. Appendix A ("Distance formulae") is absent in v1.

Cosmographic parameters (their Eq. (1)): H = (1/a) da/dt, q = −(1/a)(d²a/dt²) H⁻², j = (1/a)(d³a/dt³) H⁻³, s = (1/a)(d⁴a/dt⁴) H⁻⁴, l = (1/a)(d⁵a/dt⁵) H⁻⁵; subscript 0 = value at the present time t₀.

"We derive here some useful relations for distance related quantities as function of the redshift z and the cosmographic parameters. Using their definitions in Eqs.(1), it is easy to get for the fifth order Taylor expansion of the scale factor:

a(t)/a(t₀) = 1 + H₀(t − t₀) − (q₀/2) H₀²(t − t₀)² + (j₀/3!) H₀³(t − t₀)³ + (s₀/4!) H₀⁴(t − t₀)⁴ + (l₀/5!) H₀⁵(t − t₀)⁵ + O[(t − t₀)⁶]   (A1)

with t₀ the present day age of the universe. Note that Eq.(A1) is also the fifth order expansion of (1 + z)⁻¹, being the redshift z defined as z = a(t₀)/a(t) − 1. The physical distance travelled by a photon that is emitted at time t* and absorbed at the current epoch t₀ is

D = c ∫ dt = c(t₀ − t*)

so that inserting t* = t₀ − D/c into Eq.(A1) gives us an expression for the redshift as function of t₀ and D/c, i.e. z = z(D). Solving with respect to D up to the fifth order in z gives us the desired expansion for D(z) as:

D(z) = (cz/H₀) [D⁰_z + D¹_z z + D²_z z² + D³_z z³ + D⁴_z z⁴]   (A2)

with:
D⁰_z = 1,
D¹_z = −(1 + q₀/2),
D²_z = 1 + q₀ + q₀²/2 − j₀/6,
D³_z = −(1 + (3/2)q₀ + (3/2)q₀² + (5/8)q₀³ − (1/2)j₀ − (5/12)q₀j₀ − s₀/24),
D⁴_z = 1 + 2q₀ + 3q₀² + (5/2)q₀³ + (7/2)q₀⁴ − (5/3)q₀j₀ − (7/8)q₀²j₀ − j₀ + j₀²/12 − (1/8)q₀s₀ − s₀/6 − l₀/120."
