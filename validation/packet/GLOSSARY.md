## `Chemistry.Coexistence.IsMaxwellCoexistence`

Maxwell equal-area coexistence on the isotherm `p` (pressure as a function of molar
volume): liquid volume `vl` below gas volume `vg`, both at pressure `ps`, and the integral of the
isotherm from `vl` to `vg` equals `ps (vg − vl)`.

```lean
def IsMaxwellCoexistence (p : ℝ → ℝ) (vl vg ps : ℝ) : Prop :=
  vl < vg ∧ p vl = ps ∧ p vg = ps ∧ ∫ v in vl..vg, p v = ps * (vg - vl)
```

## `Chemistry.Coexistence.acentric`

Pitzer's acentric factor from the saturation pressure `ps` at T = 0.7 T_c and the critical
pressure `pc`: ω = −log₁₀(ps/pc) − 1.

```lean
noncomputable def acentric (ps pc : ℝ) : ℝ := -Real.logb 10 (ps / pc) - 1
```

## `Chemistry.CubicEOS.IsCriticalIsotherm`

Critical point of an isotherm `p` (pressure as a function of molar volume at fixed
temperature): zero slope and zero curvature, (∂P/∂v)_T = 0 and (∂²P/∂v²)_T = 0.

```lean
def IsCriticalIsotherm (p : ℝ → ℝ) (v : ℝ) : Prop := deriv p v = 0 ∧ deriv (deriv p) v = 0
```

## `Chemistry.CubicEOS.critCubic`

The critical cubic in `x = v_c/b`.

```lean
def critCubic (u w x : ℝ) : ℝ := x ^ 3 - 3 * x ^ 2 - 3 * (u + w) * x - (u ^ 2 + u * w - w)
```

## `Chemistry.CubicEOS.cubicP`

Generalized two-parameter cubic equation of state: pressure at temperature `T` and molar
volume `v`, `P = R T/(v − b) − a/(v² + u b v + w b²)`.

```lean
noncomputable def cubicP (R a b u w T v : ℝ) : ℝ := R * T / (v - b) - a / (v ^ 2 + u * b * v + w * b ^ 2)
```

## `Cosmography.Aviles.IsFlatLCDM`

Flat ΛCDM with matter fraction `Ω` at observation time `t₀` (Aviles et al., text before
Eq. (15)): `H = H₀ √(Ω(1+z)³ + 1 − Ω)` near `t₀`, with `H₀ > 0`.

```lean
def IsFlatLCDM (Ω : ℝ) (a : ℝ → ℝ) (t₀ : ℝ) : Prop :=
  0 < hubble a t₀ ∧ ∀ᶠ t in 𝓝 t₀, 0 < a t ∧ DifferentiableAt ℝ a t ∧
    hubble a t = hubble a t₀ * √(Ω * (1 + redshift a t₀ t) ^ 3 + 1 - Ω)
```

## `Cosmography.Aviles.cosmoCoeff`

`n`-th cosmographic coefficient `a⁽ⁿ⁾ / (a Hⁿ)` (Aviles et al. Eq. (3): j, s, l, m for
`n = 3, 4, 5, 6`; q is `-cosmoCoeff 2`).

```lean
noncomputable def cosmoCoeff (n : ℕ) (a : ℝ → ℝ) (t : ℝ) : ℝ :=
  iteratedDeriv n a t / (a t * hubble a t ^ n)
```

## `Fidelity.FriedmannCPL`

(Verbatim from `Work.Fidelity.Blind3.FriedmannCPL`, blind spec.) `FriedmannCPL Ω w₀ wₐ a t₀`: near `t₀`, `a` solves the flat Friedmann equation
(units `8πG/3 = 1`) `H² = ρ_m + ρ_de` with
* pressureless matter, `ρ_m a³ = const` [Ryd16, eq. (5.7)];
* a dark-energy fluid with CPL equation of state `w(z) = w₀ + wₐ z/(1+z)`, `z` measured from
  `t₀` [CP01; Lin03, eq. (3)]; since `z/(1+z) = 1 − a(t)/a(t₀)` this is
  `w = w₀ + wₐ (1 − a(t)/a(t₀))`, i.e. `w(a) = w₀ + wₐ(1 − a/a₀)`;
  separately conserved: `ρ̇_de + 3H(1 + w)ρ_de = 0` [Wei08, eq. (1.5.18)];
* the universe expanding at `t₀` (`ȧ(t₀) > 0`);
* `Ω = ρ_m(t₀) / ρ_crit(t₀) = ρ_m(t₀) / H₀²` (with `8πG/3 = 1`, `ρ_crit = H²`).

No sign is imposed on `Ω`, `w₀`, `wₐ` or the densities. Junk values are excluded: `a > 0`
and differentiable on a neighbourhood (so `deriv a` is the true derivative and `H` has no
zero denominator), and the expansion condition makes `H₀ > 0` so `Ω`'s defining quotient
is well-posed.

```lean
def FriedmannCPL (Ω w₀ wₐ : ℝ) (a : ℝ → ℝ) (t₀ : ℝ) : Prop :=
  ∃ ρm ρde : ℝ → ℝ,
    (∀ᶠ t in 𝓝 t₀,
      0 < a t ∧
      DifferentiableAt ℝ a t ∧
      -- flat Friedmann equation, 8πG/3 = 1
      (deriv a t / a t) ^ 2 = ρm t + ρde t ∧
      -- pressureless matter: ρ_m a³ conserved
      ρm t * a t ^ 3 = ρm t₀ * a t₀ ^ 3 ∧
      -- dark-energy continuity equation with CPL w(t) = w₀ + wₐ z/(1+z), z/(1+z) = 1 − a/a₀
      HasDerivAt ρde
        (-(3 * (deriv a t / a t) * (1 + (w₀ + wₐ * (1 - a t / a t₀))) * ρde t)) t) ∧
    -- expanding at t₀
    0 < deriv a t₀ ∧
    -- present matter density parameter
    Ω = ρm t₀ / (deriv a t₀ / a t₀) ^ 2
```

Specification of a Hubble-rate function `H a t` (scale factor `a`, cosmic time `t`).

```lean

  /-- Definition as a logarithmic derivative, `H = d ln a/dt` (Weinberg, *Cosmology* §1.5;

    HasDerivAt (fun s => Real.log (a s)) (H a t) t
  /-- de Sitter (expanding `h > 0`, contracting `h < 0`, static `h = 0`): `a = e^{ht}` has
  constant `H = h` at every time (Λ-only universe, Ryden, *Introduction to Cosmology*,
  ch. 5). -/
  deSitter : ∀ h t : ℝ, H (fun s => Real.exp (h * s)) t = h
  /-- Power law `a = tⁿ` (EdS `n = 2/3`, radiation `n = 1/2`, Milne `n = 1`): `H = n/t` at every
  `t > 0` (single-component universes, `w = 2/(3n) − 1`; Ryden ch. 5). -/
  powerLaw : ∀ n t : ℝ, 0 < t → H (fun s => s ^ n) t = n / t
  /-- Static universe (`a ≡ R > 0`): `H = 0`. -/
  static : ∀ R t : ℝ, 0 < R → H (fun _ => R) t = 0
  /-- The normalization of `a` is unphysical: `H[c a] = H[a]` (`c > 0`). -/
  rescale : ∀ c : ℝ, 0 < c → ∀ (a : ℝ → ℝ) (t : ℝ), 0 < a t → DifferentiableAt ℝ a t →
    H (fun s => c * a s) t = H a t
  /-- The origin of time is unphysical: `H[a(· + τ)](t) = H[a](t + τ)`. -/
  translate : ∀ (τ : ℝ) (a : ℝ → ℝ) (t : ℝ), 0 < a (t + τ) → DifferentiableAt ℝ a (t + τ) →
    H (fun s => a (s + τ)) t = H a (t + τ)
  /-- Time reversal turns expansion into contraction: `H[a(−·)](t) = −H[a](−t)`. -/
  timeReverse : ∀ (a : ℝ → ℝ) (t : ℝ), 0 < a (-t) → DifferentiableAt ℝ a (-t) →
    H (fun s => a (-s)) t = -H a (-t)
```

## `Fidelity.RicciFlatFLRWSpec`

Specification of the Ricci scalar of a spatially flat FLRW metric with scale factor `a`
(function of cosmic time), in the **negative** convention: `Rc a t = −6 (ä/a + (ȧ/a)²)`,
so that de Sitter (`a = c·e^{ht}`) has `R = −12 h²`.  In the common convention
(`R_c = +6(ä/a + (ȧ/a)²)`) this is `R = −R_c`.

* `law` determines `Rc a t` whenever `a(t) > 0` and `a` is twice differentiable at `t`, given
  as: `a` has derivative `a' s` at every `s` near `t`, and `a'` has derivative `a''t` at `t`
  (explicit derivative functions, so no `deriv` junk values enter).
* anchors: de Sitter, radiation `a = t^{1/2}` (`R = 0`, conformal/traceless source),
  matter `a = t^{2/3}` (`R = −4/(3t²)`; in common convention `R_c = 4/(3t²) = ρ` for
  Einstein–de Sitter with `κ² = 1`, as `R_c = κ²(ρ − 3p)`).
* invariances: rescaling `a ↦ c·a` (`c > 0`), and time translation.

```lean
structure RicciFlatFLRWSpec (Rc : (ℝ → ℝ) → ℝ → ℝ) : Prop where
  /-- Determining law: `R = −6 (ä/a + (ȧ/a)²)`. -/
  law : ∀ (a a' a'' : ℝ → ℝ) (t : ℝ), 0 < a t →
    (∀ᶠ s in 𝓝 t, HasDerivAt a (a' s) s) → HasDerivAt a' (a'' t) t →
    Rc a t = -6 * (a'' t / a t + (a' t / a t) ^ 2)
  /-- de Sitter anchor: `a = c·e^{h t}` has `R = −12 h²`. -/
  deSitter : ∀ (c h t : ℝ), 0 < c → Rc (fun s => c * Real.exp (h * s)) t = -12 * h ^ 2
  /-- Radiation anchor: `a = t^{1/2}` has `R = 0` for `t > 0`. -/
  radiation : ∀ t : ℝ, 0 < t → Rc (fun s => s ^ (1 / 2 : ℝ)) t = 0
  /-- Matter (Einstein–de Sitter) anchor: `a = t^{2/3}` has `R = −4/(3t²)` for `t > 0`. -/
  matter : ∀ t : ℝ, 0 < t → Rc (fun s => s ^ (2 / 3 : ℝ)) t = -4 / (3 * t ^ 2)
  /-- Invariance under constant rescaling of the scale factor (normalization of `a` is
  unphysical in flat FLRW). Stated under the same regularity hypotheses as `law`. -/
  scale_invariant : ∀ (a a' a'' : ℝ → ℝ) (c t : ℝ), 0 < c → 0 < a t →
    (∀ᶠ s in 𝓝 t, HasDerivAt a (a' s) s) → HasDerivAt a' (a'' t) t →
    Rc (fun s => c * a s) t = Rc a t
  /-- Invariance under time translation. Stated under the regularity hypotheses of `law`
  at the shifted time `t + τ`. -/
  time_translation : ∀ (a a' a'' : ℝ → ℝ) (τ t : ℝ), 0 < a (t + τ) →
    (∀ᶠ s in 𝓝 (t + τ), HasDerivAt a (a' s) s) → HasDerivAt a' (a'' (t + τ)) (t + τ) →
    Rc (fun s => a (s + τ)) t = Rc a (t + τ)
```

## `Sim.Duffing.IsDuffingSolution`

`x` solves the Duffing initial value problem x'' + k·x + β·x³ = 0, x(0) = x₀, x'(0) = v₀ on
the time interval [0, T], with derivatives taken within [0, T] (one-sided at the endpoints, the
weakest textbook reading): there is a velocity function `v` with x′ = v and
v′ = −k·x − β·x³ at every time in [0, T], and x(0) = x₀, v(0) = v₀.

```lean
def IsDuffingSolution (k β x₀ v₀ T : ℝ) (x : ℝ → ℝ) : Prop :=
  x 0 = x₀ ∧ ∃ v : ℝ → ℝ, v 0 = v₀ ∧ ∀ t ∈ Icc 0 T,
    HasDerivWithinAt x (v t) (Icc 0 T) t ∧ HasDerivWithinAt v (-k * x t - β * x t ^ 3) (Icc 0 T) t
```

## `Sim.MichaelisMenten.IsMMSolution`

`IsMMSolution k₁ km₁ k₂ s₀ e₀ c₀ p₀ T s e c p` (km₁ = k₋₁): the concentrations s = [S] (substrate),
e = [E] (free enzyme), c = [C] (enzyme–substrate complex), p = [P] (product) solve the
mass-action rate equations of the Michaelis–Menten mechanism E + S ⇌ C → E + P with forward,
backward and catalytic rate constants k₁, k₋₁, k₂ on the time interval [0, T]: initial values
s₀, e₀, c₀, p₀ at t = 0, and at every t ∈ [0, T] derivatives within [0, T]
s′ = −k₁ e s + k₋₁ c, e′ = −k₁ e s + (k₋₁ + k₂) c, c′ = k₁ e s − (k₋₁ + k₂) c, p′ = k₂ c.

```lean
def IsMMSolution (k₁ km₁ k₂ s₀ e₀ c₀ p₀ T : ℝ) (s e c p : ℝ → ℝ) : Prop :=
  s 0 = s₀ ∧ e 0 = e₀ ∧ c 0 = c₀ ∧ p 0 = p₀ ∧ ∀ t ∈ Icc 0 T,
    HasDerivWithinAt s (-k₁ * e t * s t + km₁ * c t) (Icc 0 T) t ∧
    HasDerivWithinAt e (-k₁ * e t * s t + (km₁ + k₂) * c t) (Icc 0 T) t ∧
    HasDerivWithinAt c (k₁ * e t * s t - (km₁ + k₂) * c t) (Icc 0 T) t ∧
    HasDerivWithinAt p (k₂ * c t) (Icc 0 T) t
```

## `Sim.Robertson.IsRobSolution`

`IsRobSolution k₁ k₂ k₃ a₀ b₀ c₀ T y₁ y₂ y₃`: the concentrations y₁ = [A], y₂ = [B],
y₃ = [C] solve the mass-action rate equations of Robertson's network A → B (k₁),
B + C → A + C (k₂), 2B → B + C (k₃) on the time interval [0, T]: initial values a₀, b₀, c₀ at
t = 0, and at every t ∈ [0, T] derivatives within [0, T]
y₁′ = −k₁ y₁ + k₂ y₂ y₃, y₂′ = k₁ y₁ − k₂ y₂ y₃ − k₃ y₂², y₃′ = k₃ y₂².

```lean
def IsRobSolution (k₁ k₂ k₃ a₀ b₀ c₀ T : ℝ) (y₁ y₂ y₃ : ℝ → ℝ) : Prop :=
  y₁ 0 = a₀ ∧ y₂ 0 = b₀ ∧ y₃ 0 = c₀ ∧ ∀ t ∈ Icc 0 T,
    HasDerivWithinAt y₁ (-k₁ * y₁ t + k₂ * y₂ t * y₃ t) (Icc 0 T) t ∧
    HasDerivWithinAt y₂ (k₁ * y₁ t - k₂ * y₂ t * y₃ t - k₃ * y₂ t ^ 2) (Icc 0 T) t ∧
    HasDerivWithinAt y₃ (k₃ * y₂ t ^ 2) (Icc 0 T) t
```
